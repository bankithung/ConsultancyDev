# ChatGPT connection icon

`backend/core/static/core/oauth/chatgpt.png` is the unmodified official ChatGPT icon provided by OpenAI's Help Center:

- Source: https://help.openai.com/en/articles/7905742-what-does-the-official-chatgpt-ios-app-icon-look-like
- Asset: https://images.ctfassets.net/j22is2dtoxu1/intercom-img-d177d076c9a5453052925143/49d5d812b0a6fcc20a14faa8c629d9fb/icon-ios-1024_401x.png

Used only to identify the registered ChatGPT OAuth client on the consent screen. Consultancy Dev remains the page's primary brand. Served locally through Django static files without a third-party image request during sign-in.
